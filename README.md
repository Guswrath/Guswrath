## 👋 Sobre mim

Cientista de dados que gosta de levar modelo e análise até o ponto em que eles viram decisão — seja um classificador de churn, um estudo de risco ou um painel que mostra, em tempo real, o que está falhando numa operação.

- 🔭 Trabalho com dados e automação de processos (RPA), construindo ferramentas de monitoramento e diagnóstico.
- 🧠 Foco em Machine Learning supervisionado, análise exploratória e visualização de dados.
- 🛠️ Quando o projeto pede, vou além do notebook: APIs em FastAPI e interfaces em Next.js.
- 📚 Estudando modelagem de risco e finanças quantitativas.
